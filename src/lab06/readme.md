# Лабораторная работа №6
## Generics и typing

### Цель работы
- Освоить систему аннотаций типов в Python (typing).
- Создать обобщённый (generic) класс `TypedCollection`.
- Понять структурную типизацию через `typing.Protocol`.

### Реализованные типы и контейнеры
В `lab06/model.py` аннотированный класс `Ticket` с методами `display()` и `score()`.

В `lab06/container.py`:
- **`TypedCollection[T]`** – generic-контейнер, аналогичный `TicketCollection` из ЛР-2, но с поддержкой произвольного типа.
- **`Displayable`** и **`Scorable`** – протоколы, описывающие наличие методов `display() → str` и `score() → float`.
- **`D = TypeVar('D', bound=Displayable)`, `S = TypeVar('S', bound=Scorable)`** – переменные типа, ограниченные соответствующими протоколами.

`TypedCollection` включает все методы из ЛР-2 (добавление, удаление, поиск, сортировка, фильтрация), а также дополнительные:
- `find(predicate)` – первый элемент, удовлетворяющий условию.
- `filter(predicate)` – отфильтрованный список.
- `map(transform)` – преобразованный список с новым типом `R`.
