## Интерфейсы и абстрактные классы (ABC)

### Цель
- Познакомиться с абстрактными базовыми классами (ABC).
- Освоить понятие интерфейса (контракта поведения).
- Научиться задавать обязательные методы для классов.
- Закрепить полиморфизм через единый интерфейс.
- Научиться проектировать архитектуру.

### Описание интерфейсов

**`Printable`** – требует метод `to_string()`, возвращающий строковое представление объекта.

**`Comparable`** – требует метод `compare_to(other)`, возвращающий результат сравнения (число -1, 0 или 1).

### Реализация в классах

**Базовый класс `BaseTicket`** (наследует `Ticket` из ЛР-1 и оба интерфейса):
- `to_string()` возвращает стандартный `__str__()`
- `compare_to()` сравнивает билеты по цене.

**`SingleTicket`** (разовый билет):
- Переопределяет `to_string()` – добавляет информацию о месте и действительности.
- Переопределяет `compare_to()` – при равенстве цен сравнивает номера мест.

**`ReturnTicket`** (билет туда-обратно):
- Переопределяет `to_string()` – выводит оба маршрута и состояние рейсов.
- Переопределяет `compare_to()` – сравнивает по суммарной цене (прямой + обратный).
