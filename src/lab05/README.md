# Лабораторная работа №5
## Функции как аргументы. Стратегии и делегаты

### Цель работы
- Освоить передачу функций как аргументов в функции и методы.
- Применять `map`, `filter`, `sorted` с пользовательскими функциями и `lambda`.
- Понять паттерн «Стратегия» и реализовать его с помощью callable-объектов.
- Интегрировать функциональный стиль с объектно-ориентированным кодом из предыдущих ЛР.

### Реализованные функции и стратегии

**Стратегии сортировки** (в `strategies.py`):
- `by_price` – по цене билета
- `by_route` – по названию маршрута
- `by_status_order` – по статусу `available` → `sold` → `used`

**Функции-фильтры**:
- `is_available` – доступные билеты
- `is_single_ticket` – только разовые билеты (`SingleTicket`)
- `make_price_filter(max_price)` – **фабрика функций**, возвращает фильтр по цене ≤ max_price

**Callable-объект (стратегия)**:
- `DiscountStrategy` – класс с методом `__call__`, уменьшает цену билета на 10%

**Расширенная коллекция** (`ExtendedTicketCollection`):
- `sort_by(key_func)` – сортировка на месте, возвращает `self`
- `filter_by(predicate)` – возвращает **новую** отфильтрованную коллекцию
- `apply(func)` – применяет функцию к каждому элементу, возвращает `self`
