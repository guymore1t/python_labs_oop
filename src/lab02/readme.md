## Лабораторная работа №2 

### Цель
- Научиться работать с коллекциями объектов.
- Понять разницу между моделью сущности и контейнером объектов.
- Реализовать собственный контейнерный класс.
- Освоить итерацию по объектам.
- Реализовать базовые операции управления коллекцией.

### Реализованный класс
**`TicketCollection`** – коллекция, хранящая объекты `Ticket` во внутреннем списке `self._items`.


### Основные методы
- add(ticket) - добавляет билет (проверяет тип и не даёт добавить билет с уже существующим номером)
- remove(ticket) - удаляет билет по объекту
- remove_at(index) - удаляет билет по индексу
- get_all() - возвращает список всех билетов
- __len__() - возвращает количество билетов
- __iter__() - чтобы можно было писать for ticket in collection
- __getitem__(index) - доступ по индексу collection[0]

### Поиск
- ind_by_number(number) - ищет билет по уникальному номеру
- find_by_route(route) - ищет все билеты с заданным маршрутом
- find_by_status(status) - ищет билеты по статусу (available, sold, used)
- find_by_price_range(min_price, max_price) - ищет билеты в заданном диапазоне цен

### Сортировка
- sort_by_price() - сортирует билеты по цене (от дешёвых к дорогим)
- sort_by_route() - сортирует билеты по названию маршрута (по алфавиту)
- sort_by_status() - сортирует билеты по статусу (available, потом sold, потом used)

### Фильтрация (возвращают новую коллекцию)
- get_available() - все доступные билеты
- get_sold() - все проданные билеты
- get_used() - все использованные билеты
- get_by_route(route) - все билеты указанного маршрута
- get_expensive(threshold) - все билеты дороже заданной цены



### В чём разница между моделью сущности и контейнером объектов?

**Сущность (`Ticket`)** отвечает за данные и поведение **одного** билета:  
- хранение маршрута, цены, статуса, уникального номера;  
- изменение статуса (`sell`, `use`, `refund`);  
- валидация собственных данных.

**Контейнер (`TicketCollection`)** отвечает за хранение, поиск, сортировку и управление **группой** билетов:  
- добавление и удаление;  
- поиск по разным критериям;  
- сортировка и фильтрация;  
- итерация и доступ по индексу.
