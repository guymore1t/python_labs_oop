# Лабораторная работа №7 — Консольное приложение

## Цель
Объединить знания ЛР1–ЛР6 в единое CLI-приложение. Реализовано интерактивное меню, управление коллекцией билетов, сохранение/загрузка данных, сортировка и фильтрация.

## Структура
- `main.py` – вход, настройка и запуск
- `cli.py` – меню, ввод/вывод
- `app.py` – бизнес-логика
- `exceptions.py` – исключения
- `storage.py` – работа с JSON
- `tickets.json` – файл данных (создаётся автоматически)

## CLI (меню)
1. Добавить билет (разовый или туда-обратно)
2. Показать все билеты
3. Найти по номеру
4. Удалить (с подтверждением)
5. Фильтрация по статусу
6. Сортировка (по цене/маршруту/статусу)
7. Сохранить в файл
0. Выход (автосохранение)
